权限与设置

为什么 Lazulite 需要特殊权限？

Lazulite 需要读取 Android 系统的音频日志，才能显示蓝牙编解码器和音频路径信息。出于隐私和安全原因，Android 会限制这些日志的访问，因此你需要通过以下三种方式之一授予权限：

方式 1：Shizuku（推荐大多数用户使用）

适合：大多数用户，尤其是希望直接在手机上设置 Lazulite 的用户

Shizuku 无需 root，即可让 Lazulite 访问所需的系统信息。在 Android 11 及更高版本上，你可以通过无线调试启动 Shizuku，无需将手机连接到电脑。设备重启后，你需要先重新启动 Shizuku，再打开 Lazulite。

▶ 视频指南：如何启用 Shizuku

方式 2：ADB（适合熟悉 ADB 的用户）

适合：已经知道如何在电脑上使用 ADB 的用户

安装 Android SDK Platform-Tools，启用 USB 调试，连接并授权手机，然后运行：

adb shell pm grant com.pedronveloso.lazulite android.permission.DUMP

方式 3：Root 权限

适合：已经 root 设备的高级用户

如果你的设备已经 root，Lazulite 可以自动请求所需权限。这是最省事的方法，但前提是你本来就熟悉 Android root 操作。

我卡在 ADB 权限页面了

第一次使用 ADB？我们建议改用 Shizuku。ADB 选项适合已经熟悉在电脑上运行命令的用户。

如果你仍想使用 ADB，请安装 Android SDK Platform-Tools，启用 USB 调试，连接并授权手机，然后运行：

adb shell pm grant com.pedronveloso.lazulite android.permission.DUMP

已经授予权限但还是不工作？ 请确认：

  • 手机已通过 USB 连接，并启用了 USB 调试
  • 手机弹出“允许 USB 调试？”提示时，你已经授权这台电脑
  • adb devices 将手机显示为 device，而不是 unauthorized
  • 你已完全按照上方内容运行授权命令

使用 Shizuku？ 请确保在启动 Lazulite 之前，Shizuku 已经在运行。

查看当前编解码器

如何查看 Android 当前使用的蓝牙编解码器？

将蓝牙音频设备连接到 Android 手机，播放音频，然后在 Lazulite 中刷新。查看当前连接显示的编解码器。

支持的编解码器列表分别说明手机和接收设备具备哪些能力，并不代表当前正在使用哪一种。

如何确认 LDAC 已启用？

开始播放并刷新 Lazulite 后，查看当前使用的编解码器是否为 LDAC。LDAC 出现在支持列表中，并不代表当前连接正在使用它。

Android 提供相关信息时，Lazulite 还会显示比特率或编码质量设置。可查看的详细信息因设备而异。

支持的编解码器和当前使用的编解码器有什么区别？

支持的编解码器分别说明手机和接收设备报告的能力。

当前使用的编解码器是双方为本次蓝牙连接协商选定的格式。

某种编解码器出现在支持列表中，并不代表播放时选用了它。

Lazulite 能更改蓝牙编解码器吗？

Lazulite 用于检查蓝牙连接，并提供相关系统设置的快捷入口。

它不会自动选择编解码器，也不能启用手机或接收设备不支持的编解码器。如果系统允许更改编解码器，需要在系统设置中操作。

设备与编解码器支持

Lazulite 支持 Android 平板电脑吗？

支持。Lazulite 既适用于手机，也支持Android 平板电脑，界面布局会适应更大的屏幕。

通过平板电脑的扬声器或有线耳机收听时，可以查看播放应用报告的输出。连接蓝牙音频设备后，还可以查看编解码器和传输详情。可用信息取决于平板电脑、Android 版本和播放应用。

Lazulite 支持哪些蓝牙编解码器？

Lazulite 可以检测并显示你的设备支持的所有蓝牙音频编解码器：

  • LDAC、aptX、aptX HD、aptX Adaptive、aptX TWS、LC3、MIHC、Opus
  • LHDC（请参阅下方的LHDC 版本支持说明）
  • AAC、SBC
  • SSC、SSC UHQ（仅限三星设备）

只要你的手机和蓝牙音频设备都支持，并且最终协商使用该格式，Lazulite 就会显示出来。

Lazulite 支持哪些 LHDC 版本？

Lazulite 已通过 LHDC V2、V3 和 V5 的测试。理论上，它应能支持所有当前及未来的 LHDC 版本。

Lazulite 只能用于蓝牙耳机吗？

不是。Lazulite 适用于各类蓝牙音频设备，包括头戴式耳机、入耳式耳机、音箱、车载音响系统和蓝牙音频接收器。

没有蓝牙连接时，使用有线耳机或手机、平板电脑的内置扬声器，也可以查看播放应用报告的输出。连接蓝牙音频设备后，还可以查看其编解码器和传输详情。可用信息取决于 Android 设备、播放应用和所连接的音频设备。

我可以把 Lazulite 用在有线耳机上吗？

可以。Lazulite 支持在使用有线耳机时查看信息，无需连接蓝牙。与通过手机或平板电脑的内置扬声器播放时一样，它会显示播放应用报告的音频输出。

播放音频并刷新后，即可查看可用的采样率、位深等信息。这些数据描述的是应用输出，并非对有线耳机或 DAC 的测量。蓝牙编解码器和传输详情仅适用于蓝牙播放。

音频路径与设备详情

为什么流媒体应用显示的编解码器有时和预期不一样？

Hi-Fi 是一个宽泛的标签，并不代表某种确切的音频格式。不同服务使用这个标签时，可能涵盖从低于 CD 音质的音频流到录音室级分辨率的音频格式。

在音频路径详情中，Lazulite 会显示播放应用报告的输出，包括信息可用时的采样率和位深，让你了解应用实际输出的格式。

通过蓝牙播放时，Android 会使用手机或平板电脑与音频设备协商选定的蓝牙编解码器，对这些输出重新编码后传输。报告的格式不能验证原始录音的保真度，也不能测量实际听感。

什么是 A2DP 硬件卸载？Lazulite 会显示它吗？

部分 Android 设备可以把蓝牙音频编码从主处理器转移到专用的音频或蓝牙硬件上处理，从而减少播放时的 CPU 负担和功耗。

Lazulite 能检测到 A2DP 硬件卸载是否启用，并显示你设备的硬件支持哪些编解码器进行卸载。某个编解码器出现在列表中，并不代表当前连接一定在使用硬件卸载，这取决于所选编解码器、连接的设备、系统设置以及制造商的具体实现。

Lazulite 的蓝牙制造商查询能识别什么？

在“设置”中开启“查询目标设备供应商”后，Lazulite 会根据所连接蓝牙音频设备的 MAC 地址前缀查询关联的制造商（如果有相关信息）。查询结果可能是蓝牙芯片制造商，而不是耳机、音箱或其他音频设备的品牌。并非每次都能查到结果，例如设备使用随机地址，或查询数据库中没有匹配记录时。

如果尚未保存偏好设置，该功能默认开启；已保存的选择会保留。你可以在“设置”中关闭此功能。开启时，Lazulite 只会把目标 MAC 地址的前三对字符发送给 MACLookup 用于识别供应商，地址的其他部分不会被发送。

隐私与数据

Lazulite 会使用我的移动数据吗？

Lazulite 的所有音频分析都在你的设备本地完成。除非你主动选择分享，否则不会有任何数据从你的手机发出。

可选崩溃诊断信息：Lazulite 不收集应用使用情况分析数据。崩溃诊断信息默认关闭；如果你开启该选项，崩溃报告和技术诊断日志可能会发送给 Google Firebase Crashlytics，以帮助提高稳定性。启用后，本地存储的报告可能会上传。

可选的供应商查询：当“设置”中的“查询目标设备供应商”开启时，Lazulite 会将已连接设备 MAC 地址的前三对字符发送给 MACLookup，以识别其制造商。地址的其他部分不会被发送，如果尚未保存偏好设置，该功能默认开启。已保存的选择会保留，你可以在“设置”中关闭此功能。

想关闭？ 前往“设置” → 关闭“崩溃诊断信息”或“查询目标设备供应商”。

使用与行为

Lazulite 会不会很耗电？

简短回答：不会，影响几乎可以忽略不计。

Lazulite 只是读取设备本来就会生成的系统日志。它不会额外创建进程，也不会在你不用时偷偷在后台运行。

注意：Lazulite 监控的是手机日志，不是蓝牙耳机本身，因此不会影响耳机电池。
