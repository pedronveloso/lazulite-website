更新情報

2026.10

新機能

  • タブレットに対応しました。Lazuliteが大きな画面をより活用できるようになりました。
  • ホーム画面に専用の「再生状態の診断」カードを追加しました。再生中の更新で新たに確認された、Androidからの報告を表示します。音声のアンダーラン（音声バッファーのデータ不足）、送信バッファーの音声データの破棄、音声接続の問題を確認できます。
  • 日本語に対応しました 🇯🇵。

改善

  • A2DPハードウェアオフロードの表示で「利用可能」と「有効」を区別するようにしました。「有効」は、システムのオフロード設定がオンで、音声を再生中かつ使用中のコーデックがオフロード対応リストに含まれている場合にのみ表示します。
  • 接続機器のBluetoothアドレスをより確実に取得できるようにし、メーカー検索や機器情報の表示を改善しました。
  • 再生先の機器の種類に合ったアイコンを表示するようにしました。スピーカー、ヘッドホン、時計、カーオーディオ、オーディオレシーバーをそれぞれ異なるアイコンで表示します。
  • バッテリー残量を表示できる接続オーディオ機器を増やしました。

修正

  • 複数の軽微な不具合を修正しました。

2026.09

  • ホーム画面を刷新し、音声経路をわかりやすくしました。
  • 再生中のアプリを確認できるようになり、より多くのAndroid端末でアプリアイコンを表示します。
  • OnePlus端末でのLDAC情報の解析精度を改善しました。
  • アプリ内の任意のアンケートで、重視する機能や感想を送れるようになりました。

2026.08

  • 再生アプリからBluetooth機器までの音声経路を確認できるようになりました。
  • 再生アプリの出力形式、サンプリング周波数、ビット深度、チャンネル数、出力経路を表示します。
  • サンプリング周波数が変換されている可能性を表示します。
  • Bluetoothと再生状態の検出を改善しました。
  • Android 10、Android 12、および新しいAndroidバージョンへの対応を改善しました。
  • API 29と、API 33を搭載した一部のLenovo端末での互換性の問題を修正しました。
  • A2DPハードウェアオフロードの状態と対応コーデックを確認できるようになりました。
  • LHDC V5とAACビットレート情報の解析を改善しました。
  • 初回設定の画面を見直し、わかりやすくしました。
  • Bluetooth、通知、システムログへのアクセス設定の案内を改善しました。
  • 再生状態に合わせた自動更新は、引き続き任意で利用できます。
  • システム設定に合わせる、ライト、ダークの3つの表示設定から選べます。
  • イタリア語に対応しました。
  • 自動更新の間隔に5秒を追加しました。
  • 接続機器のメーカーを検索する設定を追加しました。
  • 圧縮した診断ログを共有しやすくしました。
