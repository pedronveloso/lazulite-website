<h2 id="2026-08" class="changelog-version"><a href="#2026-08" aria-label="链接到版本 2026.08">2026.08</a></h2>

- 查看从播放应用到蓝牙设备的完整音频路径。
- 查看播放应用的输出格式、采样率、位深、声道和路由信息。
- 发现可能发生的采样率转换。
- 改进蓝牙和播放检测。
- 更好地支持 Android 10、Android 12 和更高版本。
- 修复 Android API 29 和部分运行 API 33 的联想设备上的兼容性问题。
- 查看 A2DP 硬件卸载状态及支持的编解码器。
- 改进 LHDC V5 和 AAC 比特率解析。
- 更清晰、重新设计的引导体验。
- 为获取蓝牙、通知和系统日志访问权限提供更清晰的指引。
- 自动播放更新仍是可选功能。
- 可在跟随系统、浅色和深色主题之间选择。
- 已新增意大利语。
- 新增 5 秒自动刷新选项。
- 可选查看已连接音频设备的制造商。
- 更方便地分享压缩诊断日志。
